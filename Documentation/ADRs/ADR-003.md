# ADR-003: Choice of Database System

## Status

Accepted

## Date

05.08.2026

## Context

The backend needs a relational database to persist the Java Classes and related data (see UML-Class-Diagram). The database choice was
left open between PostgreSQL and MySQL and must be settled before the
migration tool and the DB schema can be finalized.

## Decision

PostgreSQL is used as the relational database.

## Alternatives Considered

- **Option A:** PostgreSQL: is a common, well-documented default for self-hosted Java/Spring Boot projects.
- **Option B:** MySQL: no concrete advantage for this project and
  PostgreSQL's stricter constraint behavior fits the domain model
  better.

## Consequences

**Positive:**

- Consistent with the existing Component-Diagram, no rework needed there
- Native enum type support fits the used enums well
- Large ecosystem and documentation for self-hosted Spring Boot setups

**Negative / Trade-offs:**

- Slightly less common in shared/managed hosting environments than MySQL,
  though irrelevant here since hosting is self-managed
