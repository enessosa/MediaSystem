# ADR-004: Choice of Migration Tool

## Status

Accepted

## Date

05.08.2026

## Context

With PostgreSQL settled as the database (ADR-003), schema changes need
to be versioned and applied consistently across environments (local, CI,
production) instead of being run manually. A migration tool must be chosen
between Flyway and Liquibase.

## Decision

Flyway is used as the migration tool.

## Alternatives Considered

- **Option A:** Flyway: plain SQL migrations fit a solo project
  well, integrates with almost no configuration via Spring Boot's default
  autoconfiguration, and rollback support, which is only freely available in Liquibase
is not needed in a small project like this.


- **Option B:** Liquibase: its XML/YAML/JSON abstraction and
  built-in rollback support add more overhead than needed here, and its
  benefits (DB-independence, complex rollback scenarios) mainly pay off in
  larger teams or projects that expect to switch databases.

## Consequences

**Positive:**

- Simple migrations that are easy to write and review
- Minimal Spring Boot configuration overhead
- Good fit for a single person project without complex rollback needs

**Negative / Trade-offs:**

- No free built-in rollback. a faulty migration must be corrected with a new
  forward migration instead of an automatic rollback
