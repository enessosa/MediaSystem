# ADR-007: No Public Hosting

## Status

Accepted

## Date

21.10.2026

## Context

The original plan was to self-host MediaSystem publicly on my own server. While building the legal pages
(imprint, privacy policy) it became clear what running a public service really involves: a public imprint with
a postal address, GDPR obligations for other people's data (emails, password hashes), security updates, backups,
a server that has to be reachable all the time, and running costs. At the same time, MediaSystem is a learning
project. I probably won't use it much myself; its main purpose is to exist as a project on GitHub.

## Decision

MediaSystem is not hosted publicly. It runs locally or privately (e.g. on a home server that is only
reachable for myself or via a VPN). Phase 6 (Docker, docker-compose, reverse proxy, HTTPS) is still done, but
as a local/private deployment so that anyone can start the whole system themselves. Because of that, the imprint
and privacy policy pages were removed from the frontend. Everyone who runs their own instance uses their own
API keys (`.env`, see README).

## Alternatives Considered

- **Option A:** Public hosting as planned: real users and a live demo, but legal obligations and
  operating effort that don't pay off for a learning project.
- **Option B:** Public hosting with a c/o address service for the imprint: protects my private address,
  but costs money and leaves all other operating duties.
- **Option C:** Skip Phase 6 completely: least effort, but loses the deployment part, which is one of the
  most valuable things to learn from this project.

## Consequences

**Positive:**

- No imprint/GDPR obligations, no private address on the internet
- No server costs, no on-call responsibility for other people's data
- The deployment learning goal (Docker, reverse proxy, HTTPS) stays

**Negative / Trade-offs:**

- No live demo; the project is presented through the README, screenshots and the code
- Each user needs their own TMDB/RAWG API keys
- If public hosting is wanted later, imprint and privacy policy have to be added again
