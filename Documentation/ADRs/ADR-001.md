# ADR-001: Integrate CI Pipeline From the Start

## Status
Accepted

## Date
19.07.2026

## Context
The project is run by a single person. This creates a risk that tests
are not run manually in the heat of development, and faulty code ends up
on main by mistake.

## Decision
CI pipelines are integrated from the very start to establish a standard that
is continuously maintained throughout development. GitHub Actions will be
used for this.

## Alternatives Considered
- **Option A:** Jenkins — rejected, self-hosting would be too much overhead
- **Option B:** GitLab CI — rejected, the repository is hosted on GitHub

## Consequences

**Positive:**
- Offloads mental overhead
- Automated test logging
- Free of charge

**Negative / Trade-offs:**
- None identified
